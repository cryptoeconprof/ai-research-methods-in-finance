\section*{Course Description}
This course trains students to conduct empirical finance research using artificial
intelligence. Students will be taught how to employ finance theory and statistical
methods to specify a well-defined research question. Students will be taught how
to execute such a research inquiry using artificial intelligence tools.

\section*{Course Materials}
Course materials will be provided through GitHub with an accompanying AI teaching
assistant. The course repository is available at:
\url{https://github.com/cryptoeconprof/ai-research-methods-in-finance}.
Students are responsible for keeping an updated copy of the repository and can
ask the TA to download updates while preserving their work.

Students may use any tools they prefer. The recommended setup is the ChatGPT
desktop app:
\begin{enumerate}
\item Install the \href{https://learn.chatgpt.com/docs/app}{ChatGPT desktop app}
and sign in with a ChatGPT account.
\item Select ChatGPT, switch to Work, and open a local folder for the course.
Ask Work to clone the course's GitHub repository into that folder.
\item Select Codex, open the cloned repository as the course project, and set it
as the project's \href{https://learn.chatgpt.com/docs/projects#use-local-projects-for-folders-and-codebases}{primary folder}.
Start a new conversation to work with the course TA.
\end{enumerate}
No GitHub account or fork is required to download the repository or its updates.


\section*{Course Project}
Students will complete a team research project in teams of no more than three.
Each team will develop an empirical model that explains prediction-market
returns. Detailed instructions---including the data scope, deliverables,
deadlines, and evaluation criteria---will be announced separately.
